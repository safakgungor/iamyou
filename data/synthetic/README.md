# Synthetic data

Everything in this folder is invented for the demo. No real person is described.

| File | Contents |
| --- | --- |
| `maya/profile.json` | The demo persona: family history, settings and digital-will choice |
| `maya/vault-entries.json` | 40 vault entries (stories, opinions, conversations, corrections, style examples) dated from age 18 to 38 |
| `maya/inbox.json` | 5 sample inbox messages for the assistant demo; dates are relative (`received_days_ago`) |
| `checkin-prompts.json` | 20 check-in prompts the twin predicts answers for |
| `maya/weekly-features.json` | Generated by `scripts/generate-maya.ts` (health-baseline spec); not written by hand |

Maya's timeline is a simulation: she starts using iamyou on 2026-10-24 at age 18, and the synthetic history runs to 2048 (age 40). Every screen that shows this data carries a "Synthetic data" label.
